# liquid-glass-core

Core primitives from the Liquid Glass Design Skill.

```js
import {
  createLiquidGlassDisplacementPixels,
  createAdaptiveLiquidGlassController,
  supportsLiquidGlassSvgFilter
} from "liquid-glass-core";
```

Use this package when you want the measured displacement-map math, adaptive tinting, and browser support detection without adopting a specific framework.

The source is generated from `liquid-glass-design/assets/core/liquid-glass-core.js`; update the shared core and run `npm run sync:templates` before packing.
