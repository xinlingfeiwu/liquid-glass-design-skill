# Prompt Patterns

Use these prompts when documenting the skill or helping a user invoke it effectively. Keep the placeholders, replace only the bracketed context.

## Create A New Interface

```text
Use $liquid-glass-design to design and implement a high-end Liquid Glass [web/Electron/React] interface for [product context].

Requirements:
- choose one composition recipe before coding;
- include one focal content surface, one command surface, and one grouped secondary information area;
- use CSS/SVG refraction with measured displacement maps, not blur-only glass;
- prove the material on dark, bright, image-like, and high-frequency backdrop details;
- include hover, active, focus, reduced-motion, reduced-transparency, and fallback states;
- provide a runnable demo and update the preview screenshot.
```

## Upgrade An Existing UI

```text
Use $liquid-glass-design to upgrade this existing UI into premium Liquid Glass without replacing the product context.

First inspect the current layout and screenshot. Fix hierarchy, overlap, clipped rims, stale preview, and dock/toolbar centering before tuning glass. Then strengthen refraction, edge light, tint, dispersion, and pointer glare. Verify with screenshots plus browser geometry checks.
```

## Review A Weak Result

```text
Use $liquid-glass-design to review this Liquid Glass implementation.

Report the top issues in this order: composition, geometry, optical material, foreground clarity, accessibility, performance, fallback. Then patch the implementation and verify with a new screenshot and measurable layout checks.
```

## Build A Reusable React Component

```text
Use $liquid-glass-design to build a reusable React LiquidGlass component for [project].

Expose variant, radius, profile, strength, magnify, dispersion, blur, tint, adaptive, glare, and interactive props. Keep children sharp, filters out of layout flow, map generation cached by shape/tuning, adaptive tint sampled at low frequency, and fallback SSR-safe. Include a showcase page that exercises small pills, circular controls, text panels, and a long dock.
```

## Run Visual QA

```text
Use $liquid-glass-design to run visual QA on this Liquid Glass page at [URL].

Capture desktop and mobile screenshots, measure dock centering and focal-surface gaps, check browser fallback, and list any issues that would make the UI feel cheap, cluttered, blurry, jagged, clipped, or stale.
```
